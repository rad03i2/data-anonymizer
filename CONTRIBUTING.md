# Contributing

Contributions are welcome. Keep changes focused, dependency-light, and privacy-preserving.

1. Create a feature branch.
2. Install development dependencies: `python -m pip install -e . pytest`.
3. Run `python -m pytest` and `python -m compileall -q src`.
4. Add tests for behavior changes.
5. Never commit real personal data, production datasets, API keys, or HMAC keys.
6. Open a pull request explaining the behavior and security/privacy implications.

By contributing, you agree that your contribution is licensed under the MIT License.
